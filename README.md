An all in one Customer Relations Management program written completely in Go, using Fyne for the frontend gui. Create entries with your customer data, and update your progress from cold call to successfully closed deal.

## Running the Program

### Prerequisites
- No installation required! The executable is ready to run.

### Instructions

**On macOS/Linux:**
1. Make the file executable (if needed):
   ```bash
   chmod +x crm-gui

Run the program:
./crm-gui

On Windows:

Double-click crm-gui.exe or run from command prompt:
crm-gui.exe
